# 阿貓阿狗小時鐘｜Tun Town Clock（網頁復刻）

使用原始素材重新製作的《阿貓阿狗》小時鐘網頁版，可在瀏覽器顯示時間及角色動畫。

## 開啟方法

直接以瀏覽器開啟 `index.html`，不需要安裝其他軟體，也不需要網路。

## GitHub Pages 發布

1. 到 https://github.com/new 新增 repository，例如 `tuntown-clock`。
2. 在儲存庫點 **Add file → Upload files**，上傳 `index.html`（可另上傳本說明檔）。
3. 到 **Settings → Pages**，在 **Build and deployment → Source** 選 `Deploy from a branch`。
4. Branch 選 `main`，資料夾選 `/(root)`，儲存設定。
5. 頁面發布後，網址通常是 `https://<你的GitHub帳號>.github.io/tuntown-clock/`。

## 注意

- 網頁使用《阿貓阿狗》舊程式的原始美術素材，並非官方版本。公開發布前請確認已取得必要的授權。
- 網頁版無法完全重現舊 Windows 程式的視窗永遠置頂功能。
- 使用瀏覽器裝置的系統時間。
